# Morse Code Translator

A modern, beautiful web-based Morse Code Translator with audio playback and a sleek user interface.

## ✨ Features

- **Modern Web Interface**: Beautiful, responsive design with glassmorphism effects
- **Real-time Translation**: Instantly convert text to Morse code
- **Audio Playback**: Listen to Morse code with customizable beep sounds
- **Copy to Clipboard**: Easy copying of translated Morse code
- **Morse Code Reference**: Built-in reference guide for letters and numbers
- **Responsive Design**: Works perfectly on desktop, tablet, and mobile devices
- **Keyboard Shortcuts**: Use Ctrl+Enter to translate quickly
- **Auto-resize Input**: Dynamic textarea that grows with your content

## 🚀 Getting Started

### Option 1: Open in Browser (Recommended)
1. Simply open `index.html` in any modern web browser
2. No installation required - it works offline!

### Option 2: Local Server
1. Clone or download this repository
2. Open a terminal in the project directory
3. Start a local server:
   ```bash
   # Using Python 3
   python -m http.server 8000
   
   # Using Node.js
   npx serve .
   
   # Using PHP
   php -S localhost:8000
   ```
4. Open your browser and navigate to `http://localhost:8000`

## 🎯 How to Use

1. **Enter Text**: Type or paste your message in the input field
2. **Translate**: Click "Translate & Play" or press Ctrl+Enter
3. **Listen**: The app will play the Morse code audio automatically
4. **Copy**: Use the "Copy to Clipboard" button to copy the Morse code
5. **Stop**: Use the "Stop Audio" button to stop playback at any time
6. **Clear**: Use the clear button (×) to reset the input field
